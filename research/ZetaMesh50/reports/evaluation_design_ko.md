# 평가 전 고정 설계

50노드 실행 명세가 연구 범위·정책·완료 조건의 우선 기준이다. 5600X 문서는 Windows 환경 참고자료다. 최신 사용자 요청의 3→10→50노드 순서를 적용한다. 문서의 미제공 스타터킷·코덱을 실행한 것으로 취급하지 않는다.

학습 시드 100~103, 근사 차수 선택 150, 근사 시험 160. 네트워크 튜닝 200~204. 본 평가 1000~1029. 각 네트워크 시드는 같은 초기 조건·이동·차폐·트래픽을 공유한다. 외생 채널장은 시드·물리 시각·채널·송수신자 키로 생성하므로 정책 RNG 호출 수와 무관하다. 이동/채널장은 1초 단위이며 광고 외부 간섭은 20ms 단위다.

후보 기준선은 fixed, random, greedy, threshold, lut다. 시나리오별 튜닝 평균 성공률이 fixed보다 2%p 이상 낮지 않고, 평균 시드별 성공 전달 p95가 fixed의 1.05배 이하인 정책 중 총에너지 평균 최소를 선택한다. 같은 에너지면 위 목록 순서다. 적격 정책이 없으면 fixed를 쓴다. 선택 정책 이름과 튜닝 해시는 본 평가 전에 preregistration.json에 기록한다. 본 평가 결과로 기준선을 다시 고르지 않는다.

성공 기준은 combined의 에너지 절감률 ≥10%, 성공률 차이 ≥−0.02, p95 전달 지연 비율 증가 ≤0.05를 모두 만족하는 것이다. 각 시나리오를 따로 판정한다. 세 조건의 점추정 충족과 세 95% 신뢰구간 전체 충족을 구분한다. 신뢰구간이 경계를 가로지르면 불확실한 것으로 쓴다. 시나리오 3개가 모두 통과해야 전체 초기 성공으로 판단한다. 여러 비교에 대한 가족단위 오류율은 보정하지 않으므로 탐색적 비교다.

효과는 paired seed 단위로 구한다. 에너지 비율은 각 paired 시드의 1−E_combined/E_baseline, QoS는 성공률 절대 차이와 시드별 성공 전달 p95의 상대 차이다. 평균과 Student t 95% 신뢰구간을 사용한다. 성공 전달 0건인 시드는 지연을 결측으로 표시하며, 시드 수를 공개하고 해당 시나리오의 성공 판정을 유보한다. 성공률과 실패에 deadline을 부여한 p95도 함께 보고한다. 노드별·패킷별 관측을 독립 평가 표본으로 취급하지 않는다.

모든 정책의 PHY(legacy 1M 가정), 송신전력 0dBm, 채널 37/38/39, hop limit 4, 요구사항 및 동작 허용 범위가 같다. fixed/random/greedy/zeta_only/cheb_only는 기본 주기이며, combined/threshold/lut는 동일한 두 단계 적응 스케줄러다. 따라서 단순 적응 정책과의 비교가 통합 복잡도 실익의 핵심이다. zeta_only/cheb_only는 선택만 제거 실험하며 combined의 차이를 전부 수학적 선택 효과로 돌리지 않는다.

90초, 초기 10초 이후 주기 16초 요청, deadline 10초, 가상 정보 수명 24초·허용 연령 15초를 고정한다. 이는 단기 탐색/중계 시험이며 장시간 네트워크 생존·배터리 소진 연구가 아니다. 성공률의 절대 하한을 따로 두지 않으므로 낮은 QoS에서의 상대 충족을 서비스 실용성으로 주장하지 않는다.

민감도는 같은 본 평가 상태 체류시간에 전류 그룹별 0.75/1.25배, GNSS 0.5/2배를 적용한 전력 모형 재계산이다. 전압 공통 ±10%는 비율 순위를 바꾸지 않는다. 네트워크 민감도는 donor 비율, 수명, 차폐 손실을 각각 하나씩 바꾸어 별도 시드 3000~3004의 50노드에서 선택 기준선과 combined를 재실행한다. 본 평가 30시드와 합치지 않는다. 정책을 사후 튜닝하지 않는다.

체비쇼프 3/5/7차는 다변수 가산 성분과 1차 쌍별 상호작용항을 포함한다. 합성 예상 유용도 회귀 목표를 학습하고 선형·LUT·깊이8 결정트리·16/8 MLP와 별도 시험한다. RL teacher와 증류는 2차 범위이며 이번 모형을 RL 증류라고 부르지 않는다. PC Python 추론 시간과 미실측 MCU 비용·전체 BLE/GNSS 에너지는 구분한다.
