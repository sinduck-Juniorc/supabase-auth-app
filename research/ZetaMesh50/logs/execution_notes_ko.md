# 실행 중 확인한 문제와 처리

- 초기 기본 Python은 3.12.14였다. 프로젝트 외부의 작업 폴더에 CPython 3.11.17과 가상환경을 설치해 본 실험을 Python 3.11에서 실행했다. uv의 기본 사용자 실행파일 링크 생성은 홈 디렉터리 권한으로 실패했으나 지정한 작업 폴더의 Python 설치와 가상환경 생성은 성공했고 직접 경로로 사용했다.
- 첫 MLP 최대 반복 400에서는 수렴 경고가 있어 평가 전 최대 반복을 1000으로 늘려 같은 분리된 학습/검증/시험 시드로 재학습했다. 최종 training.log에는 이 경고가 없고 선택 차수는 5다.
- 반복 체크섬 계산이 병목이어서 불변 패킷 서명의 LRU 캐시를 추가했다. dense seed=200의 fixed/cheb_only/combined는 최적화 전 튜닝의 모든 시뮬레이션 수치와 일치했다. 핵심 테스트 26개도 다시 통과했다.
- 최종 산출물 검증에서 동결시각과 평가 시작 시각의 초 단위 문자열이 같아 엄격한 문자열 < 비교가 실패했다. 평가 명령은 동결 명령 종료 뒤 실행되었다. 동결 파일이 실행 전 소스 스냅샷 안에 동일하게 들어 있고 파일 수정시각 나노초 순서도 앞섬을 검증하도록 고쳤다. 기준선·평가 데이터·성공 기준은 변경하지 않았다. final_pipeline_initial.log에 최초 검증 실패를 보존했다.
- 기준선 p95=0초인 밀집 평가 6개 시드는 상대 지연 비율이 정의되지 않아 지연 상대효과의 유효 n=24다. 원자료의 비유한 비율을 보존하고 보고서에 유효 n과 절대 지연 차이를 추가했다. 평가 당시 소스와 최종 소스의 차이는 보고서 도구 scripts/make_report.py뿐이며 시뮬레이션 구현은 같음을 확인했다.
- 지정된 /codex/browser/projectless/0002-files-mentioned-by-the-user-uploaded-file-pointe/output 경로는 이 클라우드에 없고 상위 루트에 쓰기 권한이 없어 생성할 수 없었다. 추가 파일 권한을 사용한 mkdir는 읽기 전용 파일시스템 오류, 외부 샌드박스 mkdir는 OS 권한 거부였다. 연구 코드·결과 원본은 작업 폴더 ZetaMesh50에, 결과 묶음 준비본은 work/ready에 보존했다. 다운로드 경로 게시만 차단되었다.

## 재개

연구 실행과 결과 검증은 수행했으며 하드웨어·Windows 실측은 미실행이다. 다운로드 경로가 제공되면 work/ready의 ZIP/HTML/CSV를 복사하면 된다. 실험 재실행은 README.md의 새 --out 디렉터리 명령을 사용한다. 보고서만 다시 생성하려면 python -m scripts.make_report를 실행한다.
