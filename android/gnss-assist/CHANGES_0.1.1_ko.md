# 0.1.1 안전성 보강

2026-11-09. 0.1.0 안전성 리뷰에서 발견한 자원 해제·UI 작업·로그 한도를 보강했다.

- 각 위치 리스너와 GNSS 콜백을 독립적으로 해제한다. 실패 시 1초 뒤 한 번 재시도하고 화면 종료·파괴 시에도 정리한다. 미해제 자원이 남으면 다음 측정을 차단한다. 해제 실패가 있었던 측정은 유효 결과에서 제외한다.
- 새 측정 시작 시 이전 정리 재시도를 취소해 새 구독을 잘못 해제하지 않는다.
- 로그·내보내기는 큐 128개의 단일 작업 스레드에서 처리한다. 로그는 8MiB 한도에서 기록을 중단하고 측정 중단을 요청한다. 기존 로그를 자동 삭제하지 않는다. 내보낸 뒤 필요하면 Android 설정에서 앱 저장공간을 정리한다.
- 보조정보 요청을 별도 스레드로 이동했다. 종료된 시험의 대기 요청은 건너뛴다. 이미 시스템에 전달한 요청의 취소는 보장하지 않는다.
- 콜백과 화면 복귀 시 경과시간을 확인하며 화면에는 ‘120초 종료 예정’이라고 표시한다. 시스템 Binder·드라이버 장애까지 포함한 강제 시간 상한은 보장하지 않는다.
- S26+ / Android 17 / One UI 9를 진단 대상으로 표시하며 실제 기기 호환성은 미검증이라고 명시한다.

검증: Java 자원 해제 시험에서 첫·중간·마지막 해제가 각각 실패해도 나머지가 실행됨을 확인했다. 기존 측정 상태 검사와 Python 분석기 3개 검사도 통과했다. SDK 35로 빌드하고 APK 서명 검사를 통과했다. 기존 키로 서명한 versionCode 2 / versionName 0.1.1이다.

소프트웨어 시험은 Android 위치 서비스의 실제 실패를 재현한 계측 시험이 아니다. S26+ 설치·실제 발열·배터리·서비스 해제는 미검증이다. 시스템 호출 자체가 멈추거나 계속 실패할 때 일반 앱만으로 반드시 정리된다고 보장하지 않는다.

이전 SAFETY_REVIEW_ko.md는 0.1.0 검토 기록으로 보존한다. 새 APK 해시와 소스 해시는 verification/build.json, 빌드 로그는 verification/build-0.1.1.txt에 있다.
