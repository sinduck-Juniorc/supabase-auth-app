# 실외에서 준비하고 실내에서 확인하기

현재 배포판 0.2.1의 [로그 검증·보완 내역](WALK_VALIDATION_20261110_ko.md)을 함께 확인한다. 아래는 최초 0.2.0 사용 흐름 설명이며 0.2.1도 같은 버튼 순서를 사용한다.

새 시작 화면은 이동 관찰용이다. 기존 GNSS 비교 코드는 보존했지만 시작 화면의 A/B/C 명령을 제거해 보조정보 요청과 단순 관찰을 혼동하지 않도록 했다. 이 데모는 위치 주입·기지국 스캔·모뎀 설정 변경을 하지 않는다.

[설치 APK](downloads/ZetaMesh-Indoor-Observer.apk)

## 사용 순서

1. 기존 앱 위에 업데이트 설치한다. 같은 개발 서명, versionCode 3 / 0.2.0이다.
2. 실외에서 ‘실외 위치 준비하기’를 누르고 정확한 위치와 전화 상태 권한을 허용한다. 허용 후 준비 버튼을 다시 누른다. 통화 내용·문자·전화번호를 수집하지 않는다.
3. 새 GPS 위치를 받으면 수신을 해제한다. 최근 실외 위치의 경과 시간과 Android 추정 정확도를 확인한다. 이는 실제 오차 보증이나 실내의 현재 위치가 아니다.
4. 휴대폰 화면을 유지하며 안전하게 실내로 이동한다. 같은 지점에서 ‘실내에 도착했어요’를 누른다.
5. 잠시 관찰하고 ‘관찰 마치기’ → ‘기록 파일 저장하기’를 누른다. zetamesh-walk-*.jsonl 파일을 공유한다. 이전 gnss 파일과 형식이 다르므로 기존 GNSS TTFF 분석기에 넣지 않는다.

Wi-Fi를 켜 두어도 현재 기본 인터넷 경로와 셀룰러 관측을 구분한다. 셀룰러가 앱에서 관측되지 않는 것은 기지국이 없다는 의미가 아니다. ‘OS 검증됨’도 앱이 직접 셀룰러 패킷 전송이나 속도를 시험했다는 뜻이 아니다. VPN은 별도로 표시한다.

## 화면 및 기록

- 큰 단계 버튼, 최근 위치·인터넷 경로·휴대전화망·모바일 데이터 카드.
- 기본 데이터 SIM에 대한 서비스/데이터 상태. SIM 변경을 포함한 다중 SIM 비교는 이번 범위가 아니다.
- LTE/5G NR 등 OS가 제공한 망 종류. LTE 표기가 상태 표시줄의 5G NSA 아이콘과 다를 수 있다.
- 시작·실내 도착·종료, 상태 변화, 위치의 경과 시간·추정 정확도, 구독별 해제 성공/실패.
- 최근 위치는 메모리에서만 유지한다. 위도·경도는 로그에 넣지 않고 자동 업로드하지 않는다.

앱을 벗어나면 종료한다. 전체 5분, GPS 위치 대기 2분 종료 예정이며 시스템 정지까지 포함한 강제 상한은 아니다. 이미 준비한 실외 위치는 새 실내 위치로 바뀌지 않는다. 화면 잠금·프로세스 종료 후 관찰은 자동 재개하지 않는다.

## 자원 및 권한

로그는 별도 작업 스레드와 128개 대기열, 8MiB 한도를 사용한다. 한도 또는 쓰기 실패 시 관찰을 중단하며 기존 자료를 자동 삭제하지 않는다. 파일 내보내기도 별도 스레드에서 수행한다. 위치 해제와 전화 리스너 해제는 각각 시도한다. 해제 실패가 남으면 새 관찰을 차단한다. 위치를 얻은 직후 GPS 해제가 실패하면 이동 단계로 진행하지 않는다.

전화 상태 권한을 추가했다. 첫 관찰은 정확한 위치와 전화 상태 권한 모두 필요하다. 거부 시 자동 시작하지 않으며 안내를 표시한다. 이 권한은 위치 주입이나 무선 제어 권한이 아니다. 온도·소비 전력 측정 및 가속 성능 비교는 이 버전에 포함하지 않았다.

## 검증과 한계

SDK 35 빌드, 서명 검사, Java 위치 입력 경계 검사(이전 캐시·미래 시각·5초 초과 위치·mock 거부), 기존 자원 정리 예외 검사, Python 분석기 검사 3개를 통과했다. 검증 로그는 verification/build-0.2.0.txt와 analyze-tests-0.2.0.txt에 있다.

클라우드에 Android 에뮬레이터와 연결된 S26+가 없어 새 UI의 실제 렌더링, Android 17 권한 팝업, 삼성 전화 상태 콜백, 실제 이동과 자원 해제는 미검증이다. 이전 0.1.1의 실물 GNSS 성공을 새 0.2.0 전체의 검증으로 간주하지 않는다. 이 로그는 환경 관찰용이며 위치가 통신을 가속했다는 인과관계나 RF 탐색 시간을 직접 측정하지 않는다.
