## 2026-11-10 · 분리 준비

기준: zetamesh-v2.0.0, 앱 0.2.1. 아직 V3 기능 또는 V3 APK의 구현·실기기 검증을 완료한 것은 아니다.

- 개발 브랜치: development/v3
- 별도 앱 식별자: org.zetamesh.gnss.v3
- 이후 각 변경에는 목적 / 변경 파일 / 검증 / 실물 결과 / 알려진 제한 / V2 회귀 필요 여부를 기록한다.
