# 노트북 → 스마트폰 → UNO R4 WiFi 자동 BLE 중계

노트북 한 대가 숫자를 만들고 스마트폰 한 대가 중계하며 R4 한 대가 결과를 표시한다. 같은 APK를 여러 폰에서 실행하면 노트북이 입력마다 중계할 폰을 한 대 선택한다. BLE 제조사 데이터 광고를 두 무선 구간에서 사용한다.

## 실행

1. [실행 파일 묶음](downloads/EcoRelay-Kit.zip)을 풀고 Arduino IDE에서 `EcoRelaySink/EcoRelaySink.ino`를 연다. 헤더를 같은 폴더에 둔다. 보드는 **Arduino UNO R4 WiFi**, 코어는 Arduino UNO R4 Boards 1.6.0, 라이브러리는 ArduinoBLE 2.1.0 및 Arduino_SpiNINA 0.0.2를 사용한다. 업로드하면 보드의 현재 스케치가 교체된다.
2. Android 11 이상 스마트폰에 `EcoRelay.apk`를 설치하고 Bluetooth를 켠다. **에코 트레킹 BLE 중계 → 중계 시작**을 누르고 권한을 허용한 뒤 화면을 열어 둔다. Android 11에서 스캔하려면 기기의 위치 설정도 켠다. R4 광고를 받으면 화면에 **R4 발견**이 표시된다.
3. BLE 스캔과 광고를 지원하는 Windows 10/11 x64 노트북에서 Bluetooth를 켜고 `EcoRelay.exe`를 실행한다. 첫 값은 0이고 이후 1과 0을 번갈아 생성한다. 콘솔에서 후보 수·선택 확률·순번·로컬 광고 결과를 확인한다. 종료는 Ctrl+C다.
4. R4의 내장 LED는 받은 값이 1이면 켜지고 0이면 꺼진다. 세션·순번·숫자를 비교하려면 IDE 시리얼 모니터를 115200 baud로 열어 출력을 읽는다. 보드는 전원만 연결해도 작동한다.

## 품질 추정과 후보 선택

R4는 약 2초마다 300ms 동안 부팅 식별자와 증가하는 순번을 광고하고 나머지 시간에 중계 광고를 듣는다. 폰은 최근 5초 이내에 R4를 발견했을 때 후보 광고를 보낸다. 노트북은 관측이 만료된 후보를 제거하고 새 후보를 기다린다.

노트북은 [연구 모델](../../research/ZetaMesh50/models/quality.json)에 저장된 5차 체비쇼프 계수와 교차항을 사용한다. 두 구간에서 관측한 RSSI 중 약한 값, 폰 배터리 잔량, R4 관측 경과 시간, 중계 횟수 1, 폰에서 본 R4 비콘 수신 추정값, GNSS 품질 기본값 0.1을 입력한다. RSSI는 후보 광고와 R4 비콘에서 얻으므로 반대 방향 데이터 전송 품질은 실측이 필요하다. 비콘 수신 추정값은 초기 0.1에서 새 비콘마다 기존 값의 75%와 순번 간격 역수의 25%를 합산한다. 배터리 정보가 없으면 연구 기본값 0.2를 쓴다.

품질 점수 내림차순으로 순위 r을 정하고 동점이면 폰의 임시 식별자 순으로 정렬한다. 최상위 점수를 q, 후보 수를 N이라고 할 때 각 후보의 선택 확률은 `0.9 × r^-(1+q) / Σ k^-(1+q) + 0.1/N`이다. 폰 한 대의 선택 확률은 1이다. [기준 정책](../../research/ZetaMesh50/policies/combined.py)

## 광고 형식과 수신 판정

시험용 제조사 ID는 `0xffff`다. 제조사 ID 뒤에 공통 헤더 `ZR`, 버전 1, 종류 1바이트를 붙인다. 다중 바이트 정수는 리틀 엔디언이다.

| 종류 | 헤더 다음 필드 | 제조사 ID 제외 길이 |
|---|---|---|
| 1 · R4 비콘 | 부팅 ID 2, 비콘 순번 2 | 8바이트 |
| 2 · 폰 후보 | 폰 ID 4, 배터리 백분율 1, R4 RSSI 1, 비콘 수신 추정 백분율 1, 관측 경과 초 1 | 12바이트 |
| 3 · 노트북 입력 | 선택한 폰 ID 4, 송신 세션 4, 순번 4, 숫자 1 | 17바이트 |
| 4 · 폰 중계 | 원래 폰 ID·세션·순번·숫자 | 17바이트 |

노트북은 종류 3을 약 1.2초 광고한다. 지정된 폰은 종류를 4로 바꿔 약 1.5초 광고한다. R4는 종류 4만 처리한다. 폰과 R4는 같은 송신 세션의 중복·역순 입력을 걸러 낸다. 최종 수신은 R4 출력에서 노트북과 같은 순번·값을 찾아 확인한다. 실물 전달률과 배터리 소모량 측정은 별도 시험이다.
