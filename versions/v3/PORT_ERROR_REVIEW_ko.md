# 포트 오류 검토

## 공개 자료 조사 결과

2026-11-10 삼성 개발자/지원 도메인에서 AT commands, Galaxy, 3GPP AT, SM-S947N을 조사했으나 해당 모델·펌웨어의 포트별 허용 명령표를 확인하지 못했다. 이는 문서가 존재하지 않는다는 증명이나 단말 기능 부재의 증명이 아니다. 삼성 커뮤니티 사용자 글·다른 모델/모뎀 자료는 이 모델의 공식 허용표로 사용하지 않는다.

공식 표준: ETSI TS 127 007 V17.5.0 9.1/9.2절.
https://www.etsi.org/deliver/etsi_ts/127000_127099/127007/17.05.00_60/ts_127007v170500p.pdf

CME 오류는 숫자 또는 문구로 전달될 수 있고 CMEE 설정은 그 형식을 바꾼다. 현재 오류는 이미 CME 접두사가 있어 설정을 바꿔야 한다는 근거가 없다. 3은 operation not allowed, 4는 operation not supported로 정의돼 있지만 아직 어느 코드인지 관찰하지 못했다. 이 코드의 표준 의미와 실제 단말 원인을 구분한다.

## 도구에서 확인한 한계와 최소 보완

기존 CSQ 도구가 오류 접두사만 보존하고 상세를 버렸다. 보완본은 숫자 0..65535, 소수의 표준 오류 문구와 정확히 일치하는 분류, 제한된 not supported/not allowed/permission denied 문구 단서만 저장한다. 임의 오류 문구는 원문으로 남기지 않고 기존 마스킹 형식/길이로 처리한다. 문구 단서는 표준 코드와 동등하지 않으며 장치 전체 미지원 판정 근거도 아니다.

고정 AT+CSQ 한 번, 설정·시간·상한·close는 그대로다. CMEE/초기화/리셋/다른 명령은 추가하지 않았다. 실제 전송은 아직 하지 않았다. 이 보완은 과거 파일에서 버린 내용을 복구하지 못한다.

## 사용자 옵션 자료 우선 검토

사용자 요청에 따라 추가 실측 안내 전에 DEVICE_PREFLIGHT_ko.md의 옵션 자료 재검토를 완료했다. 예전 JSONL 촬영 당시 AT 옵션 off와 이후 사용자 on·재부팅 보고를 구분한다. 개발자 옵션에 CSQ 오류를 자동 해결하는 스위치가 있다고 확인되지 않았다. 재전송을 바로 진행하지 않고 필요하다면 현재 AT 옵션 상태를 화면에서 읽기만 한 뒤 진단 1회 필요성을 판단한다.

검증: 오류 코드/정확한 문구/비표준 단서/개인정보 미보존/미등록 숫자 코드 5개 신규 모의 시험 포함 전체 51개 통과. 단말 보완본 실측은 미실행이다.
